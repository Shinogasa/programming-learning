# programming-learning

設計判断とコード学習の記録を集める公開リポジトリです。実作業で本人が何を調べ、選び、変更し、検証したかを、支援の範囲とともに残します。記録件数や正答率だけで習得・成長を断定しません。

## 構成

- `legacy/decision/`: 以前の学習記録99件。公開用に抽象化した取込元の本文を、取込時に変更せず保存しています。旧形式の結論一致は独立した能力の証拠に変換しません。
- `imports/`: 取込元commit、相対path、SHA-256を含む照合用manifest。
- `records/`: 今後の設計判断・コード技能の記録。実証した範囲、支援、再試行、別文脈での確認を区別します。
- `operations/`: 発火、skip、中断、再開などの運用記録。能力の証拠には数えません。
- `.learning-store.json`: store IDと取込状態。ローカルのbindingはこのリポジトリに含めません。

新しい記録は学習store CLIで保存します。ファイル保存、Git commit、remote反映は別々に確認します。保存時はstore directory自体を排他し、lock fileは作りません。markerのschema version 2はこの方式を識別します。

## 公開情報の境界

社名、組織・顧客名、内部ホスト・URL・path、非公開コードやデータを記録しません。本文だけでなくファイル名、能力ID、operation、manifestも確認します。安全な抽象化で判断や証拠が失われる場合は保存を見送ります。

このリポジトリは本人の学習過程の記録です。模擬対話やAIが作成・実行したテストは、本人が自力で検証した証拠として扱いません。
